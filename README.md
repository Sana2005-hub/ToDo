A basic to-do list application developed using HTML, designed to add, display, and manage tasks in a simple and user-friendly interface. The project focuses on understanding webpage structure and semantic HTML elements.

Features

(1)Add, edit, and delete tasks – Manage daily tasks efficiently

(2)Dark/Light Mode toggle – Switch themes for better accessibility and comfort

(3)Persistent task list (optional) – Tasks can be saved locally using localStorage (if implemented)

(4)Responsive layout – Works well on desktop and mobile devices

(5)Clean UI – Minimal design for easy readability and interaction

(6)Semantic HTML structure – Built using accessible and maintainable HTML elements

Tech Stack: Basic HTML
